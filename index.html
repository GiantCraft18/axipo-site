Создавай регулярные резервные копии важных данных. Храни хотя бы одну копию отдельно от основного устройства.

BACKUP

Проверяй разрешения приложений, активные сессии и подключённые устройства. Отзывай ненужный доступ.

PRIVACY

Загрузка файлов

Загружай программы только с официальных сайтов или проверенных репозиториев. Не отключай защиту ради неизвестного файла.

SAFE DOWNLOADS

Базовый чек-лист

  • Уникальные пароли для важных аккаунтов.
  • MFA включена, где доступна.
  • ОС и приложения обновлены.
  • Резервные копии создаются и проверяются.
  • Неизвестные файлы не запускаются.
  • Активные сессии регулярно проверяются.
/ THREAT_DATABASE

База угроз

Справочник распространённых классов вредоносного ПО. Название угрозы само по себе не доказывает заражение.

Важные различия

Malware — вредоносное ПО. Exploit — способ использования уязвимости. RCE — выполнение кода удалённо, а не отдельное семейство malware. Data exfiltration — несанкционированный вывод данных.

/ AXIPRO_PROJECTS / EXTERAGUARD

ExteraGuard

Проект AXIPRO, посвящённый статическому анализу подозрительных плагинов и повышению осведомлённости о рисках.

PLUGIN SECURITYSTATIC ANALYSISANDROID / DESKTOP

Возможности версии 4.4.0

  • Статический анализ файлов по эвристическим признакам.
  • Проверка целостности с использованием SHA-256.
  • Пользовательский карантин с возможностью восстановления.
  • Отчёты о найденных подозрительных конструкциях.

Реальная совместимость и поведение должны проверяться на целевых версиях exteraGram и exDesktop.

Ограничения

ExteraGuard не является полноценным антивирусом. Статический анализ не гарантирует обнаружение всех угроз и может давать ложные срабатывания. Он не заменяет ручной анализ кода и осторожность пользователя.

Перед установкой плагина

  1. Проверь источник и репутацию автора.
  2. Изучи код, если он доступен.
  3. Обрати внимание на сетевые запросы, динамическое выполнение и сбор данных.
  4. Не устанавливай файл, если его назначение непонятно.
/ TOOLS / STATIC_PLUGIN_CHECKER

Plugin Checker

Локальная предварительная проверка текстового содержимого файла на отдельные подозрительные признаки. Файл не отправляется на сервер и не исполняется.

Выбери файл для анализа

Только текстовые файлы. Максимальный размер: 2 МБ.
Файл не выбран

Что ищет проверка

Эвристики отмечают некоторые признаки: динамическое выполнение кода, декодирование Base64, сетевые URL, вызовы subprocess и сочетания этих конструкций. Наличие совпадения не доказывает вредоносность: такие конструкции встречаются и в легитимных программах.

Это демонстрационный анализатор, а не полноценный движок ExteraGuard или антивирус. Он не анализирует бинарные файлы и не обнаруживает все варианты обфускации.

AXIPRO / SECURITY

Почему статический анализ не даёт абсолютной гарантии

Статический анализ помогает находить подозрительные конструкции без запуска файла. Обфускация и динамическая загрузка кода могут скрывать поведение. Результаты нужно трактовать как сигналы для дальнейшего исследования.

/ SECURITY_GUIDES

Инструкции

Практические алгоритмы для снижения повседневных цифровых рисков.

Как безопасно проверить плагин

  1. Уточни, кто разработчик и где опубликован проект.
  2. Проверь, соответствует ли запрашиваемый доступ назначению плагина.
  3. Если доступен исходный код, обрати внимание на неизвестные сетевые адреса, загрузку удалённого кода и динамическое выполнение.
  4. Проверь файл несколькими средствами, понимая ограничения каждого.
  5. Не устанавливай файл, если остаются существенные сомнения.

Что делать при подозрении на кражу аккаунта

  1. С безопасного устройства смени пароль.
  2. Заверши неизвестные активные сессии.
  3. Включи MFA и проверь способы восстановления.
  4. Проверь другие аккаунты на повторное использование пароля.
  5. Предупреди контакты, если от твоего имени могли отправлять сообщения.

Как распознать фишинг

  • Срочность, угрозы блокировки или обещания награды.
  • Несовпадающий домен или сокращённая ссылка.
  • Запрос пароля, кода подтверждения или seed-фразы.
  • Неожиданный файл или просьба установить неизвестное приложение.
